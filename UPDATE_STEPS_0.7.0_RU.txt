ALEX BOARD 0.7.0 — КАК УСТАНОВИТЬ ОБНОВЛЕНИЕ

ПОРЯДОК ВАЖЕН: СНАЧАЛА SUPABASE, ПОТОМ GITHUB.

1. SUPABASE
- Открой Edge Functions → ably-token → Code → Edit/Deploy new version.
- Удали старый index.ts.
- Вставь весь код из supabase/functions/ably-token/index.ts.
- Нажми Deploy updates.
- В Settings функции оставь Verify JWT with legacy secret выключенным.

2. GITHUB
- Открой репозиторий alex → Code → Add file → Upload files.
- Перетащи содержимое update-архива с сохранением путей.
- Подтверди замену файлов.
- Commit message: Fix realtime gaps, bring-to-me and group transforms
- Нажми Commit changes.
- Открой Actions и дождись зелёных build и deploy.

3. ОБЯЗАТЕЛЬНО ЗАКРОЙ СТАРЫЕ ВКЛАДКИ
Новые клиенты используют событие live-batch. Старые открытые вкладки нужно полностью закрыть и открыть заново.

4. ПРОВЕРКА
- Одна доска в двух окнах/устройствах.
- Напиши 3x-5y+6=18x-3 несколькими отдельными штрихами: на втором экране символы не должны исчезать.
- Нажми «Ко мне»: второй экран должен принять центр и масштаб преподавателя.
- Выдели 10–30 объектов и двигай/вращай/масштабируй: группа должна двигаться в реальном времени.
- Обнови обе страницы и проверь сохранение.
