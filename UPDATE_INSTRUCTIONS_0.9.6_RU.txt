ALEX BOARD 0.9.6 — УСТАНОВКА

1. В Supabase откройте SQL Editor.
2. Полностью выполните файл:
   supabase/collaboration_upgrade_0.9.6.sql

   Он запускается ПОСЛЕ уже установленного collaboration_upgrade_0.9.5.sql.
   Успешный результат:
   Alex Board 0.9.6 operation journal and bulk copy upgrade installed

3. Загрузите всё содержимое архива 0.9.6 в корень GitHub-репозитория с заменой старых файлов.
4. Дождитесь успешного GitHub Pages build/deploy.
5. Полностью закройте старые вкладки доски на всех устройствах и откройте их заново.

ПРОВЕРКА

1. На большой доске нарисуйте один штрих и подождите 5–10 секунд.
   Интерфейс больше не должен подвисать из-за полного canvas.toJSON().
2. Отключите интернет, создайте несколько объектов, обновите страницу после восстановления соединения.
   Pending-операции должны восстановиться из IndexedDB и отправиться в Supabase.
3. Удалите объект, нажмите Undo, затем Redo.
   Объект должен вернуться и снова удалиться с тем же objectId.
4. Скопируйте несколько объектов, вернитесь в список досок, откройте другую доску и нажмите Ctrl/Cmd+V или кнопку «Вставить».
5. Скопируйте доску кнопкой «Копировать». Если на исходной доске были ожидающие операции, они сначала должны подтвердиться сервером.
6. Для большой вставки проверьте, что в Supabase появляются временные строки board_import_chunks, а после успешного commit они удаляются.
