ALEX BOARD — ПОДКЛЮЧЕНИЕ ABLY 20 ГЦ

ЧТО УЖЕ ДОЛЖНО БЫТЬ ГОТОВО
- В Ably создан ключ supabase-token-server.
- В Supabase Edge Function Secrets сохранён ABLY_API_KEY.
- Функция ably-token уже создана.
- В Settings функции выключен Verify JWT with legacy secret.

ШАГ 1. ОБНОВИТЬ EDGE FUNCTION
1. Открой Supabase → Edge Functions → ably-token.
2. Открой вкладку Code.
3. Нажми редактирование кода / Deploy updates.
4. Удали старый код.
5. Открой файл из архива:
   supabase/functions/ably-token/index.ts
6. Скопируй весь код и вставь в редактор Supabase.
7. Нажми Deploy updates.

Зачем обновлять функцию:
новая версия проверяет boardId + секретный ключ ссылки на доску через Supabase,
и только после этого выдаёт временный токен Ably для конкретного канала.

ШАГ 2. ПРОВЕРИТЬ ФУНКЦИЮ
Тестовый boardId из прошлого теста больше не подойдёт без настоящего boardKey.
Проще проверить уже после публикации сайта, открыв настоящую доску в двух окнах.

ШАГ 3. ЗАГРУЗИТЬ ПРОЕКТ В GITHUB
1. Открой репозиторий alex.
2. Загрузить содержимое папки alex-board-ably-20hz с заменой файлов.
3. Commit message:
   Add Ably realtime 20Hz
4. Нажми Commit changes.
5. Открой Actions и дождись Success.

ШАГ 4. ПРОВЕРКА
1. Открой одну и ту же доску на компьютере и телефоне/в режиме инкогнито.
2. Подвигай объект непрерывно 5–10 секунд.
3. Проверь рисование и курсоры.
4. Отпусти объект и обнови обе страницы — конечное положение должно сохраниться.

КАК ТЕПЕРЬ РАБОТАЕТ
- Ably: курсоры, живое рисование, перемещение, масштабирование, поворот,
  выделение, блокировки и другие мгновенные события.
- Supabase: окончательное состояние доски, изображения, история и восстановление.
- GitHub Pages: интерфейс сайта.

ЧАСТОТА
- курсор: максимум 20 сообщений/сек;
- перемещение/масштаб/поворот: максимум 20 сообщений/сек;
- живое рисование: пакеты максимум 20 раз/сек;
- финальная позиция сохраняется отдельно после завершения действия.

АВАРИЙНЫЙ РЕЖИМ
Если Ably не загрузится или токен не будет выдан, код автоматически попробует
использовать прежний Supabase Realtime, поэтому доска не должна полностью остановиться.

ПРОВЕРКА ИСПРАВЛЕНИЙ 0.7.0
1. Напишите подряд много отдельных символов на одном устройстве. На втором уже написанное не должно исчезать.
2. На устройстве преподавателя измените масштаб и положение, затем нажмите «Ко мне». Ученик должен перейти к тому же центру и масштабу.
3. Выделите 10–30 объектов, двигайте, масштабируйте и вращайте. На втором устройстве вся группа должна двигаться сразу, а не прыгать после снятия выделения.
4. После проверки обновите обе страницы: окончательное состояние должно сохраниться.

ОПТИМИЗАЦИЯ ABLY
- Частота живых обновлений остаётся 20 Гц.
- События одного 50-мс окна объединяются в один live-batch.
- Карандаш отправляет только новые точки, а не всю линию заново.
- Группа отправляет одну матрицу временного proxy-объекта.
- Повторяющиеся состояния отбрасываются до отправки.
- echoMessages выключен, поэтому отправитель не получает собственный пакет обратно.
