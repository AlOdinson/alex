# Alex Board 1.31.18 — Per-object convergence fence

## Исправлена причина расхождения координат

- Для каждого объекта хранится последняя подтверждённая Supabase операция и её версия.
- Запоздавший live-кадр больше не может перезаписать уже применённое серверное положение, даже если у кадра и операции одинаковый `updatedAt`.
- Каждый временный transform, текст, удаление, фон и групповая операция несут `baseRevision`; поэтому отклонённый конкурентный жест отсекается по причинному порядку, а не по несравнимым часам двух iPad.
- После окончания перемещения адресная проверка ждёт подтверждение именно затронутых ID и при необходимости восстанавливает только их.
- Прерванная live-сессия также завершается адресной сверкой своих объектов.

## Одновременная работа и группы

- После подтверждения групповой операции её временный proxy получает серверный барьер: задержанные `start`, `style` и `operation` не могут создать группу повторно.
- При конфликте двух участников подтверждённые версии конфликтующих объектов устанавливаются заново перед повторением более поздних локальных действий.
- Проверка охватывает добавление, удаление, transform, вставки, текст, картинки, стили, Undo/Redo и групповые операции через единый журнал.

## Нагрузка

- Полного периодического обхода доски нет.
- 30-секундный heartbeat по-прежнему читает только номер ревизии.
- Память и работа адресной страховки пропорциональны текущим объектам и числу ID в конкретном действии.

## Проверка выпуска

- Production-сборка Vite.
- Детерминированный тест позднего live `end`, равной версии и отклонённого конкурентного жеста с более новым временем на другом устройстве.
- Два браузерных клиента: групповая вставка, поворот и атомарное удаление с одинаковым результатом на обеих досках.
