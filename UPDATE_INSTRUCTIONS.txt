ALEX BOARD 0.8.1 — ОБНОВЛЕНИЕ С 0.7.4 ИЛИ 0.8.0

1. Загрузить содержимое update-архива в корень GitHub-репозитория alex с заменой файлов. Архив уже содержит первую игру и подходит и для 0.7.4, и для 0.8.0.
2. В Supabase открыть SQL Editor и один раз полностью выполнить:
   supabase/game_library_visibility_upgrade_0.8.1.sql
3. Дождаться зелёного build/deploy во вкладке GitHub Actions.
4. Полностью закрыть старые вкладки доски на всех устройствах и открыть их заново.
5. Проверить владельцем последовательность → ← → ←.
6. Кнопка «Игротека» должна появиться у всех участников; повторная последовательность должна скрыть её.

Последовательность работает только у владельца доски, не работает во время ввода текста и должна быть набрана за 3 секунды.
