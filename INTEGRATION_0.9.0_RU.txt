ALEX BOARD 0.9.0 — ОБЩАЯ ИГРОВАЯ КОМНАТА

ЧТО ДОБАВЛЕНО
- До 4 участников в одной игровой комнате.
- Один участник играет, остальные смотрят.
- Контрольное состояние передаётся 5 раз в секунду.
- Нажатия клавиш, джойстик, ответы, пауза, выбор сложности и перезапуск передаются сразу.
- Активный игрок может добровольно передать управление.
- Преподаватель может принудительно забрать управление.
- Ученики не могут самостоятельно отбирать управление.
- Если активный игрок пропал, через 3 секунды управление переходит преподавателю,
  а при его отсутствии — первому оставшемуся участнику.
- Пробел ставит игру на паузу на компьютере.
- На телефоне есть кнопка паузы слева сверху и экранный джойстик.
- Мобильная камера следует за божьей коровкой и держит её около центра экрана.
- Когда преподаватель повторно нажимает → ← → ←, игротека закрывается,
  открытые игры принудительно возвращаются на доску, а кнопка исчезает.

ВАЖНО
Для доски остаётся прежний Ably-аккаунт и Edge Function ably-token.
Для игр используется отдельный Ably-аккаунт или отдельное Ably-приложение с ключом ABLY_GAME_API_KEY.

ШАГ 1. СОЗДАЙ ИГРОВОЙ ABLY
1. Открой второй Ably-аккаунт/проект, который будет использоваться только играми.
2. Создай API key с publish, subscribe и presence.
3. Скопируй полный ключ вида app.keyId:secret.

ШАГ 2. ДОБАВЬ СЕКРЕТ В SUPABASE
Supabase → Edge Functions → Secrets:

ABLY_GAME_API_KEY=полный_ключ_второго_Ably

Старый ABLY_API_KEY не удаляй: он продолжает обслуживать доску.

ШАГ 3. СОЗДАЙ И РАЗВЕРНИ ДВЕ EDGE FUNCTIONS
Создай функцию ably-game-token и вставь весь файл:

supabase/functions/ably-game-token/index.ts

Создай функцию ably-game-control и вставь весь файл:

supabase/functions/ably-game-control/index.ts

Для обеих функций отключи Legacy JWT verification, как уже сделано у ably-token,
и нажми Deploy.

ably-game-token:
- проверяет ключ доступа к доске;
- выдаёт токен только для игровой комнаты этой доски;
- разрешает publish, subscribe и presence.

ably-game-control:
- принимает только ссылку владельца;
- отправляет force-exit во все открытые игры этой доски,
  когда преподаватель скрывает игротеку.

ШАГ 4. GITHUB
Загрузи файлы обновления в корень репозитория с заменой.
Дождись зелёной галочки GitHub Actions.

НОВЫЙ SQL НЕ НУЖЕН
SQL game_library_visibility_upgrade_0.8.1.sql, который уже был выполнен,
остаётся достаточным. Повторно запускать его не требуется.

ПРОВЕРКА
1. Открой доску по ссылке владельца и гостевую ссылку в другом браузере.
2. Нажми владельцем → ← → ← — кнопка игротеки появится у обоих.
3. Открой одну игру на обоих устройствах.
4. Первый вошедший управляет, второй наблюдает.
5. Проверь движение, ответы и паузу: пробел на ПК, кнопка сверху слева на телефоне.
6. Передай управление другому участнику.
7. Владельцем нажми «Забрать управление».
8. Верни владельца на доску и повторно нажми → ← → ←.
   Все оставшиеся в игре должны вернуться на доску, а кнопка должна исчезнуть.

РЕЖИМ БЕЗ ИГРОВОГО ABLY
Если новые Edge Functions или ABLY_GAME_API_KEY ещё не настроены,
игра запускается в одиночном режиме. Совместный просмотр, эстафета
и удалённый force-exit начнут работать после настройки игрового Ably.
