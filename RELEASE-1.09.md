# Alex Board 1.09

Основа: 1.08.

## Исправлено

- Отложенное завершение рамочного выделения теперь имеет generation token и отменяется при смене инструмента, Undo/Redo, удалении и новом выделении.
- Callback рамки повторно проверяет активный инструмент и текущий Canvas перед созданием ActiveSelection.
- Нажатие любой кнопки инструмента гарантированно сбрасывает текущее выделение и освобождает локальные блокировки.
- Пустой ActiveSelection автоматически удаляется; оболочка с одним живым объектом превращается в обычное одиночное выделение.
- После группового перемещения ActiveSelection не создаётся повторно: групповая операция остаётся в Undo, а временная оболочка снимается.
- При новом рамочном выделении старое выделение и изменённые контролы очищаются до создания рамки.
- Таймер завершения выделения очищается при размонтировании доски.

## Совместимость

- Форматы Ably, Supabase, snapshot и истории не менялись.
- Объектный ластик и Pencil fallback не изменялись.
- Групповое перемещение по-прежнему записывается одной transform-операцией.
