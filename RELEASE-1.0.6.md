# Alex Board 1.0.6 — Apple Pencil tool-switch lifecycle fix

Исправлен пропуск первого штриха Apple Pencil после переключения между карандашом, линией и фигурами.

Изменения:

- Apple Pencil и touch больше не используют явный `setPointerCapture()`; Safari уже предоставляет им неявный захват указателя.
- Явный pointer capture сохранён только для мыши.
- Поздний `lostpointercapture` Apple Pencil больше не отменяет новую сессию рисования.
- Нативный `pointercancel` Apple Pencil вне pinch-жеста завершает объект на последней принятой точке вместо удаления первого штриха.
- Добавлена проверка координат и последовательности событий, чтобы поздние терминальные события предыдущего контакта не завершали новую сессию с повторно использованным `pointerId`.
- Ably, Supabase, realtime, история, серверные RPC и формат объектов не изменялись.
