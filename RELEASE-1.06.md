# Alex Board 1.06

Основа: версия 1.05.

## Производительность

- Добавлен локальный реестр объектов по `boardObjectId`: обычный Undo/Redo больше не ищет объект полным обходом Canvas.
- Реестр поддерживает временные дубликаты через `Map<id, Set<object>>`, поэтому live-preview и подтверждённый объект не конфликтуют.
- После полного snapshot реестр перестраивается заново; при редкой рассинхронизации предусмотрен безопасный fallback-поиск и самовосстановление реестра.
- Undo/Redo применяет интерактивность только к восстановленным объектам и делает один итоговый рендер.
- События `selection:created`, `selection:updated` и `selection:cleared` больше не запускают полный `applyObjectInteractivity()` для всей доски. Обновляются только прошлые и текущие участники выделения.
- Групповое выделение больше не запускает массовый обход при создании временного proxy и при его подтверждении.
- После локального перемещения/масштабирования выполняется точечная дедупликация только изменённых ID вместо полной `deduplicateBoardObjects()`.
- Remote-lock обновляет только объекты с указанными ID.

## Объектный ластик

- Список объектов и их границы вычисляются один раз в начале жеста, а не на каждом движении Pencil.
- На время жеста строится безопасный временный пространственный индекс по ячейкам; он не хранится между жестами и поэтому не может рассинхронизироваться с remote-трансформациями.
- Очень крупные объекты помещаются в отдельный список кандидатов, чтобы не создавать тысячи ячеек.
- Z-index сохраняется из снимка начала жеста без повторного `indexOf()` по всей доске.
- Удаления рендерятся максимум один раз за animation frame.
- Состояние выделения обновляется один раз на жест, а не после каждого удалённого объекта.
- Undo объектного ластика по-прежнему восстанавливает все объекты одной исторической операцией.

## Что намеренно оставлено

Полный обход сохраняется только в редких целостностных сценариях: первоначальная загрузка, применение полного snapshot, смена прав доступа и аварийное восстановление realtime. Это сделано для сохранения корректности.

Рамочное выделение по-прежнему выполняет одну точную проверку объектов при отпускании рамки. Постоянный spatial index для курсора в этот релиз не добавлялся, чтобы не допустить пропусков после удалённых трансформаций. Обычный клик и работа с уже выбранными объектами полного обхода больше не вызывают.

## Не изменялось

- Формат Ably/Supabase сообщений и операций.
- Формат snapshot и история Undo/Redo.
- Stylus TouchEvent fallback из 1.0.13.
- Двухпальцевый zoom, palm rejection и создание карандаша/линий/фигур.
