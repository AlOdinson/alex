ALEX BOARD 0.7.4 — БЫСТРЫЕ ПАКЕТНЫЕ ВСТАВКА И УДАЛЕНИЕ

Исправлено:
1. Вставка большого количества объектов больше не применяется на принимающем устройстве по одному. Части одного paste-пакета сначала собираются, затем объекты создаются одним enliven-вызовом и появляются за одну перерисовку.
2. Очередь постоянных операций больше не отправляет десятки последовательных запросов Supabase. До 120 действий и до безопасного размера данных объединяются в один запрос.
3. Несколько операций над одним объектом внутри одной пачки схлопываются до последней. Например, линия, которую создали и тут же удалили, не должна возвращаться из старого queued-upsert.
4. Любое удаление сначала мгновенно публикует список ID через Ably, а сохранение удаления в Supabase идёт отдельно в пакетной очереди.
5. Объектный ластик отправляет удаляемые ID на второе устройство небольшими группами примерно каждые 32 мс, поэтому не ждёт конца длинного движения и не создаёт 40 отдельных постоянных запросов.
6. Поздние draw/preview/upsert/snapshot не могут вернуть недавно удалённую линию: принимающее устройство хранит временную tombstone-метку до подтверждения Supabase.
7. Быстрые карандашные штрихи привязываются к правильной Fabric-линии по стартовой координате. Это устраняет появление посторонних линий из-за перепутанных creationSessionId.
8. Выделенные линии удаляются клавишами Delete и Backspace, включая клавишу удаления на Mac.

Установка:
1. В Supabase и Ably ничего не менять.
2. Распаковать update-архив.
3. GitHub → репозиторий alex → Add file → Upload files.
4. Перетащить содержимое распакованной папки в корень репозитория с заменой.
5. Нажать Commit changes.
6. Дождаться зелёного Actions.
7. Полностью закрыть старые вкладки доски на обоих устройствах и открыть доску заново.

Проверка:
- вставить одновременно 30–50 скопированных объектов;
- быстро нарисовать 15–20 отдельных штрихов;
- удалить их объектным ластиком одним непрерывным движением;
- выделить несколько линий и нажать Delete/Backspace;
- после теста обновить принимающую страницу: удалённые объекты не должны возвращаться.
