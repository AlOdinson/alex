# Alex Board 1.32.10 — возвращён исходный ввод Apple Pencil

Версия возвращает способ рисования Apple Pencil из исходной доски 1.31.14:
Fabric снова использует свой проверенный iPad-путь `touchstart/touchmove/touchend`,
а не включённый в 1.32.2 режим `enablePointerEvents`.

Удалён неэффективный обходной `preventDefault` из 1.32.9: он не мог вернуть Fabric
прежний набор слушателей событий.

При этом сохранены независимо работающие улучшения:

- во время переноса Fabric не ищет выбранный объект среди всей заполненной доски на
  каждом движении;
- остаются точное выделение, защита от ладони и чистый pinch-zoom;
- authoritative operation log v8, лёгкие transform-операции и адресная синхронизация
  не менялись;
- структура данных и SQL Supabase не менялись.
