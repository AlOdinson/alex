# Alex Board 1.0.8 — Immediate Apple Pencil tool switching

- Tool buttons now apply select/pencil/line/eraser/text immediately on Pencil/touch pointerdown instead of waiting for delayed click.
- The Shapes button and individual shape choices use the same immediate activation path.
- Delayed compatibility clicks are suppressed so they cannot toggle a tool or palette a second time.
- Canvas creation, selection, erasing, Ably, Supabase, RPC, Undo/Redo and object formats are unchanged.
