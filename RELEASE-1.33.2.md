# Alex Board 1.33.2 — защищённый резервный канал Mac

- WebRTC остаётся основным транспортом удалённого браузера.
- При недоступности P2P зритель автоматически получает JPEG-кадры через защищённый WebSocket-туннель Mac.
- Первый сохранённый кадр отправляется каждому новому зрителю немедленно.
- Команды управления и состояние панели используют тот же резервный путь.
- Сессионный ключ меняется при каждом запуске браузера и уничтожается при остановке.
- Публичный туннель не открывает локальную панель управления и API сервера.
- SQL и схема Supabase не изменялись.
