# Alex Board 0.7.1 — Ably 20 Hz Low Latency

Совместная онлайн-доска для занятий с GitHub Pages, Supabase и Ably.

## Realtime

- курсор, рисование и перемещение публикуются напрямую, без последовательной сетевой очереди;
- частота живых обновлений — до 20 раз в секунду (каждые 50 мс);
- экран продолжает отрисовываться браузером с обычной частотой кадров;
- готовое состояние сохраняется в Supabase;
- при сбое Ably остаётся автоматический fallback на Supabase Realtime.

## Экономия без задержки

- `echoMessages: false` — отправитель не получает собственное событие обратно;
- новые точки карандаша передаются дельтами, а полный объект сохраняется в Supabase;
- большая выделенная группа двигается одной временной группой и одной матрицей;
- одинаковые трансформации, курсоры и виды повторно не отправляются;
- во время рисования и трансформации курсор едет внутри того же сообщения, без отдельной публикации;
- временным токенам Ably не выдаётся разрешение `history`.
