# Alex Board 0.5.8

Совместная онлайн-доска для занятий с синхронизацией между компьютерами, iPad, iPhone и Android.

## Что добавлено в 0.5.8

- меню фигур открывается через portal прямо под кнопкой и больше не прячется за панелью;
- копирование и вставка передают на все устройства один и тот же пакет абсолютных координат;
- вставленная группа не запускает преждевременную транзакцию выделения, поэтому не исчезает и не смещается у других участников;
- серверное подтверждение вставки ожидается перед показом статуса завершения;
- кнопка «Автопилот» удалена у всех пользователей;
- кнопка преподавателя «Ко мне» сохранена.

## Обновление существующего проекта

1. Полностью закройте старые вкладки доски на всех устройствах.
2. Скопируйте содержимое update-архива с заменой в папку проекта.
3. Не удаляйте свой файл `.env`.
4. Новый SQL и `npm install` для версии 0.5.8 не нужны.
5. Выполните:

```bash
cd /Users/alik/Downloads/alex-board-mvp
npm run build
```

6. После успешной сборки загрузите новую папку `dist` в Netlify → Deploys.
7. Заново откройте интернет-ссылку на всех устройствах.
