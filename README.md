# Alex Board 0.9.7 — быстрая очередь и построчное хранение объектов

Версия 0.9.7 устраняет нарастающие подвисания при быстром письме на большой доске.

## Что изменено

- новый штрих записывается в IndexedDB без чтения всей ожидающей очереди;
- для отправки курсором берутся только первые 32 действия с ограничением размера;
- несколько отдельных действий передаются одним RPC-пакетом, но сохраняют собственные `actionId`, ревизии и Undo/Redo-границы;
- подтверждение пакета удаляет pending-записи одной транзакцией IndexedDB;
- публикация подтверждений в Ably больше не блокирует отправку следующего серверного пакета;
- Supabase хранит объекты в `board_objects` и меняет только затронутые строки;
- полный `boards.snapshot` больше не пересобирается после каждого штриха;
- серверный checkpoint создаётся раз в 1000 принятых ревизий;
- порядок слоёв, групповое восстановление и Undo/Redo применяются атомарно;
- обычное изменение объекта сохраняет его серверный порядок без пересчёта ранга всех объектов;
- проверка целостности больше не вызывает `canvas.toJSON()`;
- во время рисования отключён дорогой поиск объектов под указателем;
- pixel-perfect hit testing включается только для объектного ластика;
- отключено Retina-масштабирование внутреннего Canvas и включено отсечение объектов вне экрана.

## Установка

Сначала полностью выполните в Supabase SQL Editor:

```text
supabase/collaboration_upgrade_0.9.7.sql
```

Успешный результат:

```text
Alex Board 0.9.7 fast queue and row object storage installed
```

После этого загрузите содержимое проекта в GitHub с заменой старых файлов.

Подробный порядок установки находится в `UPDATE_INSTRUCTIONS_0.9.7_RU.txt`.
Техническая схема находится в `INTEGRATION_0.9.7_RU.txt`.
