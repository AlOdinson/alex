ALEX BOARD 0.9.5 — КАК УСТАНОВИТЬ

1. Открой Supabase Dashboard → SQL Editor.
2. Полностью выполни файл:
   supabase/collaboration_upgrade_0.9.5.sql
3. Убедись, что в результате появилась строка:
   Alex Board 0.9.5 collaboration upgrade installed
4. Загрузи содержимое архива 0.9.5 в корень GitHub-репозитория с заменой файлов.
5. Дождись зелёной галочки GitHub Actions / завершения деплоя.
6. На всех устройствах полностью обнови страницу сайта. На iPhone/iPad при необходимости закрой старую вкладку и открой ссылку заново.

ВАЖНО

- SQL 0.9.5 обязателен. Без него клиент временно использует аварийное восстановление полным снимком вместо нового журнала операций.
- Повторно разворачивать Edge Functions не нужно.
- Менять секреты или тариф Ably не нужно.
- Старые доски и ссылки сохраняются.
- Файлы предыдущих SQL удалять или запускать заново не нужно, если они уже были установлены.

БЫСТРАЯ ПРОВЕРКА ПОСЛЕ ДЕПЛОЯ

1. Открой одну доску на двух устройствах.
2. Нарисуй линию на первом устройстве — она должна появиться сразу на втором.
3. Перемести несколько выделенных объектов группой — они должны переместиться вместе без копий.
4. Проверь Undo и Redo на обоих устройствах.
5. Оставь доску открытой больше 30 секунд и убедись, что объекты не исчезают и Canvas не мигает.
6. Отключи интернет на одном устройстве, сделай действие, включи интернет и дождись восстановления очереди.
7. Проверь порядок слоёв кнопками «вперёд/назад».
