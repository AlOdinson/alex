# Alex Board 1.0.13

Основа: Alex Board 1.0.3.

Изменения:

- кнопки инструментов Apple Pencil активирует непосредственно через непассивный `touchstart`;
- совместимый отложенный `click` после stylus-touch подавляется;
- добавлен резервный маршрут `touchType === 'stylus'` для холста;
- если WebKit не прислал обычный pen `pointerdown`, TouchEvent немедленно преобразуется в существующий pen-поток доски;
- если Pointer Events работают нормально, резервный маршрут не включается;
- поздние нативные pen-события того же контакта отбрасываются, чтобы не создавать двойной штрих;
- палм-риджект, двухпальцевый zoom, Ably, Supabase, сохранение и форматы операций сохранены из 1.0.3.

Ограничение: если iPadOS не передаст странице ни PointerEvent, ни TouchEvent для слишком быстрого второго контакта, веб-код не сможет восстановить отсутствующее событие.
