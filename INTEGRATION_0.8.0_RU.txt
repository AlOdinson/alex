ALEX BOARD 0.8.0 — ПЕРВАЯ ИГРА В ИГРОТЕКЕ

Что добавлено

1. В верхней панели доски появилась кнопка «Игротека».
2. Добавлен отдельный экран игротеки с первой игрой:
   «Жучок и процентный лабиринт».
3. Игра запускается в изолированном iframe и не конфликтует со стилями,
   клавиатурой и Fabric canvas доски.
4. При переходе в игротеку доска полностью размонтируется:
   - отключается realtime доски;
   - удаляются обработчики клавиатуры и указателя;
   - Fabric canvas освобождается;
   - локальный снимок сохраняется перед переключением.
5. При возвращении компонент доски создаётся заново, загружает актуальный
   снимок из Supabase и снова подключает realtime.
6. Каждый участник переключается независимо. Один пользователь может остаться
   на доске, пока второй играет.
7. В игру добавлен минимальный bridge через postMessage:
   GAME_READY, GAME_STARTED, GAME_FINISHED и GAME_STATE. Он понадобится для
   следующего этапа с общей игровой сессией.

Что пока не добавлено

- общий игровой Ably;
- синхронизация состояния 5 раз в секунду;
- мгновенная передача игровых действий;
- до четырёх участников в одной игровой сессии;
- передача и перехват эстафеты;
- сохранение полноценного игрового состояния в Supabase.

Как обновить

1. Загрузить содержимое архива в корень репозитория alex с заменой файлов.
2. Дождаться завершения GitHub Actions / Pages deployment.
3. Полностью закрыть старые вкладки доски.
4. Открыть доску, нажать «Игротека», запустить игру и вернуться на доску.

Supabase SQL, Edge Function ably-token и текущий Ably-аккаунт для доски
на этом этапе менять не требуется.
