# Alex Board 1.33.1 — единый транспорт Mac-браузера

- Служебная вкладка Mac теперь, как и обычная доска, автоматически переходит с Ably на Supabase Realtime, если Edge Function `ably-token` недоступна.
- Mac и iPad больше не могут молча оказаться в разных сигнальных каналах.
- Локальный сервер сообщает выбранный транспорт в диагностическом статусе.
- Уже опубликованная доска 1.33.0 поддерживается локальным сервером: он направляет служебную вкладку в рабочий Supabase fallback.
- SQL и схема данных не менялись.
