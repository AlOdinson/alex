# Alex Board 1.32.18 — безопасная совместная работа

- Supabase выдаёт атомарную аренду на каждый выделенный объект. Пока объект выделен одним участником, другой участник не может выделить, переместить или изменить его.
- Любая серверная операция дополнительно отвергается, если затрагивает объект, занятый другим участником. Одновременные касания больше не могут разъехаться между устройствами.
- Undo/Redo отменяет только собственные неизменённые поля. Чужие более поздние изменения сохраняются; конфликтующие части пропускаются адресно.
- Картинка остаётся недоступной для выделения и редактирования, пока конкретное устройство полностью не загрузило и не декодировало файл.
- Горячий путь рисования Apple Pencil не изменён: серверные аренды запускаются только при выделении объектов.

Перед публикацией клиента один раз примените `supabase/collaboration_safety_v8.sql`.
