# Board notebook

Approved scope: toolbar button between text and eraser creates a near-square notebook; bottom previous/page/next controls, no previous on first page; next creates pages lazily, no fixed page count. Pencil, lines, shapes, editable whole text and static images are supported. PDF/GIF are excluded. Content crossing the boundary splits into a page fragment and board fragment; split text is rasterized, undo restores source text. Notebook moves as a whole and resizes uniformly from corners. Current page is shared. Page navigation is not editing history. Content/fragment changes form atomic history actions and use existing authority leases.

Represent the notebook as one registered Fabric group with serialized pages, loading only the current page. Page changes and content edits use the notebook's existing board object identity and authority lock. Whole text remains editable through the notebook text editor. Page fragments retain clipping in notebook coordinates; outside fragments retain complementary clipping on the board.

Verification must cover boundary clipping, partial text rasterization, whole-text editing, no unsupported media, serialization/reload, uniform transforms, undo/redo and remote authority reconciliation. Do not publish unless end-to-end tests pass.
