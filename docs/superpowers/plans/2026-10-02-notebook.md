# Board Notebook Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add collaborative, paginated notebooks with clipped page content and reversible edits.

**Architecture:** Registered Fabric group stores serialized pages and renders only the active page. Board adapters convert content insertion/splitting into existing atomic authority operations and history records. Notebook identity participates in existing leases; the toolbar and React page controls delegate mutations to Board.

**Tech Stack:** React, Fabric 7, current browser authority/history protocol, IndexedDB.

**Spec:** docs/superpowers/specs/2026-10-02-notebook.md

## Global Constraints
- No PDF or GIF inside notebook pages.
- Cut text becomes raster; whole text remains editable.
- Corner-only proportional resizing; no fixed page-count limit.
- One logical edit equals one undo/redo action; navigation does not add history.

## Review Focus
- Drawing crosses the boundary or only touches an edge: complementary fragments, no lost pixels.
- Remote edit races page flip: leases reject/serialize conflicting writes.
- Partial text undo: restore editable original, no duplicated fragments.
- Reload after hidden-page edits: preserve all pages and source assets.
- Notebook in multi-selection/copy/delete: contents remain attached and undo restores pages.
