# Alex Board 1.32.17 — мгновенное выделение после снятия Pencil

Уточнённый сценарий разделил два разных пути iPadOS: после настоящего Pencil-drag
следующее выделение начиналось сразу, а после короткого касания по пустому месту
WebKit создавал отложенную совместимую пару `mousedown`/`mouseup`. Диагностика
1.32.15 зафиксировала эту пару через 39 мс после Pencil-up.

- Для основного Apple Pencil `pointerdown` в инструменте выделения теперь отменяется
  только браузерное действие по умолчанию. По стандарту Pointer Events это подавляет
  совместимые мышиные дубли короткого Pencil-тапа.
- Распространение PointerEvent не останавливается: Fabric по-прежнему получает тот же
  `pointerdown`, выполняет точный поиск линии, снимает выделение и начинает перенос или
  новую рамку без синтетического ввода.
- Палец, мышь, карандаш, ластик, пипетка, текст и жесты масштабирования не используют
  новый путь.
- Диагностика записывает, был ли мышиный дубль подавлен для каждого Pencil-контакта.
- Синхронизация и SQL Supabase не менялись.
