# Alex Board 1.0.4 — Unified Creation Input

## Главное изменение

Карандаш, прямая линия и геометрические фигуры переведены на единый нативный маршрут ввода:

`pointerdown → pointermove → pointerup / pointercancel`

Каждый создающий инструмент подключается через общий интерфейс `begin / move / end / cancel` и реестр инструментов. Текущий физический контакт закрепляется за инструментом, который был выбран в момент касания. Переключение кнопки инструмента влияет только на следующее касание.

## Защита от задержек

- Активная сессия ввода освобождается до завершения realtime, истории и сохранения.
- Готовые объекты сохраняются через отдельную фоновую очередь по одному объекту.
- Очередь не выполняет сериализацию во время активного контакта и уступает ожидающему браузерному вводу, когда доступен `isInputPending`.
- Ожидание `path:created` у карандаша больше не блокирует следующий физический контакт.
- Обычное переключение инструментов не создаёт синтетический `pointerup`, не ждёт таймер и не сбрасывает чужую сессию.
- Карандаш использует отдельный экземпляр `PencilBrush`, поэтому настройки нового инструмента не меняют уже начатый штрих.
- Превью линий и фигур больше не очищает `contextTop`, пока им владеет свободный штрих карандаша.
- Ожидающие commit-операции защищены от серверной ревизии и принудительно сбрасываются перед размонтированием доски.

## Совместимость

- Существующая palm rejection остаётся общей перед новым контроллером.
- Двухпальцевый zoom и передача Pencil → pinch сохранены.
- Частичный ластик остаётся отдельным Fabric-инструментом; внутренний Fabric fallback используется только для его аварийного завершения при жесте.
- Выделение, трансформации, текст, вставка изображений и объектный ластик не переведены на новый контроллер и сохраняют прежнее поведение.

## Расширение

Новый создающий инструмент можно подключить регистрацией обработчика в `creationToolRegistryRef` без изменения общего ввода Apple Pencil, touch и mouse.

## Проверки выпуска

- Выполнена синтаксическая проверка всех JS/JSX-файлов через TypeScript parser.
- Выполнены статические проверки отсутствия старых `lineRef`, `lineStartRef`, `shapeDraftRef` и старого отдельного завершения creation draft.
- Проверена последовательность: `activeSession = null` выполняется до `tool.end()`.

Полноценный Vite build в среде подготовки выпуска требует установки npm-зависимостей. Финальную проверку Apple Pencil, palm rejection и pinch zoom следует выполнить на реальном iPad перед заменой основной опубликованной версии.
