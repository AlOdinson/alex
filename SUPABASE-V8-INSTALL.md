# Установка Supabase v8

1. Откройте проект Supabase, который используется GitHub Pages.
2. Перейдите в **SQL Editor → New query**.
3. Вставьте целиком содержимое `supabase/authoritative_log_v8.sql` и нажмите **Run**.
4. Убедитесь, что запрос завершился без ошибки.
5. Только после этого загрузите версию 1.32.0 на GitHub.

Миграция создаёт новый журнал и канал ревизий, переносит прежний журнал при стандартной схеме `board_actions`, включает realtime для серверной головы и отзывает права на старые RPC записи. Снимки остаются только быстрым стартовым кэшем; активная синхронизация никогда не сканирует всю доску.

Если SQL не установлен, доска покажет ошибку о необходимости `authoritative_log_v8.sql`. Это намеренное поведение: продолжать работу через старую схему опаснее, чем явно остановить запись.
