# Alex Board 1.23

## Changes

- Phone autopilot follows the teacher at 50% of the teacher zoom, keeping more context visible.
- Pasted objects and uploaded images switch to the cursor tool and select the latest inserted object or batch.
- New text enters editing immediately and opens the compact keyboard on touch devices.
- Enter, the compact keyboard enter/done keys, or tapping outside finishes text editing, clears selection, and switches to cursor.
- Empty or whitespace-only text is deleted automatically on finish. Shift+Enter remains available for a desktop line break.
- Clicking the zoom percentage restores 100% while preserving the current scene centre.
- The iPad shape palette uses a smaller five-column layout.
- Image upload uses a native file-input hit target so Apple Pencil can open the picker.
