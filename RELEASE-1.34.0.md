# Alex Board 1.34.0

- Добавлен вход учителя по email magic link через Supabase Auth.
- Сессия аккаунта безопасно сохраняется на устройстве и автоматически обновляется.
- Новые доски связываются с `auth.uid()`; старые локальные доски заявляются аккаунтом только по совпадающему owner-key hash.
- Добавлена одноразовая привязка Mac восьмизначным кодом без передачи ключа владельца доски локальному серверу.
- Токен Mac хранится только локально, в Supabase записывается SHA-256 hash.
- Доступ к аккаунтным данным реализован через проверяющие RPC; таблицы закрыты RLS и прямые права отозваны.
- Запрос старта Mac повторно проверяет одновременно токен компьютера, владельца аккаунта и ключ доступа конкретной доски.
- Удалённый браузер обнаруживается через случайный account capability channel, а видеосигнализация идёт через отдельный board capability channel.
- Объектная синхронизация, Apple Pencil и инструменты доски не изменялись.
- Сохранены Full HD 1920×1080, адаптивная частота, WebRTC и защищённый Cloudflare fallback.

SQL: `supabase/teacher_account_mac_v9.sql`.
