# Alex Board 1.0.11 — Native Pencil tap transaction removal

- Main drawing-tool switches no longer render as native HTML buttons.
- Tool selection is committed on the physical pointerdown.
- Compatibility click generation is suppressed before Safari can hold the next Pencil contact.
- Shape choices and eraser-mode switches use the same non-native pointer control.
- Keyboard Enter/Space activation remains available.
- Canvas, Ably, Supabase, realtime operations, storage and object formats are unchanged.
