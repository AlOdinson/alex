# Alex Board 1.27

## Мгновенное выделение и перемещение Apple Pencil

- Точная попиксельная проверка включается только на один `pointerdown`, а не на каждое наведение и движение Pencil.
- Один физический контакт Pencil имеет одну сессию курсора; совместимые mouse-события Safari после отпускания отбрасываются.
- Поток `pointermove` Pencil ограничен одним событием на кадр, поэтому Fabric не обрабатывает несколько одинаковых перемещений между двумя перерисовками.
- Рамка выделения перенесена из Fabric Canvas в лёгкий DOM-overlay и больше не заставляет перерисовывать всю доску при каждом движении.
- Рамочное выделение использует векторную геометрию Fabric вместо `toCanvasElement()` + `getImageData()` для каждого объекта.
- Повторный `object:modified` от одного жеста Safari отбрасывается до сериализации и записи в очередь.
- При перемещении используются закэшированные сериализации объектов: длинный Pencil-path не сериализуется заново целиком только из-за изменения координат.
- Индексы объектов для live-transform вычисляются один раз на сессию вместо `indexOf()` для каждого объекта каждые 50 мс.
- `pointercancel`, потеря фокуса и размонтирование очищают рамку, live-transform и блокировки.
- Задержка запуска durable-очереди уменьшена со 160 до 60 мс.

## Совместимость

Сохранён прежний формат durable `upsert`, поэтому обновление не требует изменения Supabase RPC или миграции существующих досок.
