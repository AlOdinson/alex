Alex Board 0.9.9 — исправление Apple Pencil

Причина ошибки 0.9.8:
обработчик touch-событий отменял весь TouchEvent во время Pencil. На iPadOS этот поток может содержать сам Pencil, поэтому Fabric не получал штрих.

Установка:
1. Новый SQL выполнять НЕ нужно.
2. Замени файлы проекта содержимым архива 0.9.9.
3. Дождись завершения GitHub Pages deploy.
4. Полностью закрой старую вкладку Safari на iPad.
5. Открой сайт заново. Для обхода кэша один раз можно открыть адрес с окончанием ?v=099.
6. Выбери карандаш и сначала проверь Pencil без ладони, затем Pencil с ладонью, затем один палец и два пальца.

Ожидаемое поведение:
- Apple Pencil рисует сразу;
- ладонь не начинает pinch и не завершает штрих;
- один палец рисует при выбранном карандаше;
- два пальца без Pencil перемещают и масштабируют доску;
- маленькие соседние штрихи не удаляются как ложные дубликаты.
