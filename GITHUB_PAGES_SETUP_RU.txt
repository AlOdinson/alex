ALEX BOARD — ПУБЛИКАЦИЯ В РЕПОЗИТОРИИ alex

Будущий адрес:
https://alodinson.github.io/alex/

1. РАСПАКУЙ ЭТОТ ZIP
Внутри будет папка alex-board-github-pages-alex-ready.

2. ЗАГРУЗИ СОДЕРЖИМОЕ ПАПКИ В РЕПОЗИТОРИЙ alex
На странице пустого репозитория нажми:
uploading an existing file

Перетащи ВСЮ распакованную папку в область загрузки.
Важно: должна попасть скрытая папка .github с workflow.

Веб-интерфейс GitHub разрешает до 100 файлов за одну загрузку.
В этом проекте файлов меньше 100.

Внизу:
Commit message: Initial Alex Board upload
Нажми Commit changes.

3. ДОБАВЬ СЕКРЕТЫ SUPABASE
GitHub:
Settings → Secrets and variables → Actions → New repository secret

Добавь:
VITE_SUPABASE_URL
VITE_SUPABASE_PUBLISHABLE_KEY

Значения возьми из Netlify:
Site configuration → Environment variables

Не добавляй SUPABASE_SERVICE_ROLE_KEY.

4. ВКЛЮЧИ PAGES
Settings → Pages → Build and deployment → Source → GitHub Actions

5. ЗАПУСТИ ДЕПЛОЙ
Actions → Deploy Alex Board to GitHub Pages
Если запуск не начался автоматически:
Run workflow → Run workflow

6. ОТКРОЙ САЙТ
После зелёной галочки:
https://alodinson.github.io/alex/

Прямые ссылки на комнаты будут иметь вид:
https://alodinson.github.io/alex/board/ID?key=...

Эта версия специально исправлена для пути /alex/.
