ALEX BOARD 0.9.7 — ПРОВЕРКА СБОРКИ

ПРОЙДЕНО

1. Синтаксическая проверка Node.js для файлов src/lib/*.js и vite.config.js.
2. Разбор всех 20 JS/JSX-файлов компилятором TypeScript с режимом React JSX.
3. Проверка всех относительных импортов: отсутствующих локальных файлов не найдено.
4. Проверка архитектуры очереди:
   - горячий путь не использует getAll() всей pending-очереди;
   - первые действия выбираются составным IndexedDB-курсорным индексом;
   - до 32 логических действий отправляются одним RPC-пакетом;
   - счётчик очереди обновляется без полного повторного чтения;
   - подтверждение пакета выполняется одной IndexedDB-транзакцией;
   - Ably-публикация не блокирует следующий серверный пакет.
5. Проверка серверной архитектуры:
   - создана таблица board_objects;
   - обычное действие не переписывает boards.snapshot;
   - checkpoint вызывается только на каждой 1000-й принятой ревизии;
   - пакет прекращается на отклонённом действии, более поздние действия остаются pending;
   - 17 SQL-функций имеют 17 корректно закрытых $$-тел.
6. Проверка воспроизведения операций на JSON-состоянии:
   - групповое удаление;
   - Undo-восстановление с теми же objectId;
   - групповая перестановка слоёв;
   - обычное изменение с preserveOrder;
   - добавление нового объекта и изменение фона.
7. Проверка отсутствия фактического вызова canvas.toJSON() в Board.jsx.

ОГРАНИЧЕНИЯ ПРОВЕРКИ В ЭТОЙ СРЕДЕ

- Полную Vite-сборку выполнить не удалось: npm registry не ответил до тайм-аута, поэтому зависимости не были загружены.
- SQL прошёл структурную статическую проверку, но не был реально выполнен внутри проекта Supabase из этой среды.
- После установки обязательны практические тесты из UPDATE_INSTRUCTIONS_0.9.7_RU.txt, особенно поток из 100–200 штрихов в двух окнах.
