# Alex Board 1.05

Основа: стабильная версия 1.0.13.

## Изменения

- Переключение инструментов больше не вызывает полный обход `canvas.getObjects()`.
- Карандаш, линия, фигуры, частичный и объектный ластик, текст и курсор переключаются через глобальный режим Canvas за O(1).
- Только инструмент выделения включает Fabric target finding; остальные инструменты используют собственный маршрут ввода.
- Обычные объекты постоянно остаются готовыми к выделению, а режим рисования изолирует их через `skipTargetFind`.
- Линии и фигуры, созданные в режиме рисования, сразу получают корректную интерактивность для будущего выделения.
- Текст использует точечный hit-test только в момент касания вместо массового изменения всех объектов.
- Нормализация свойств всех объектов выполняется при загрузке/синхронизации и изменении блокировок, но не при смене инструмента.
- Stylus TouchEvent fallback из 1.0.13 сохранён без изменений.

## Не изменялось

- Ably/Supabase и форматы realtime-сообщений.
- Undo/Redo и формат сохранённых операций.
- Двухпальцевый зум и защита от ладони.
