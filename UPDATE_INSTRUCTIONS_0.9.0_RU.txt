ALEX BOARD 0.9.0 — КАК УСТАНОВИТЬ ОБНОВЛЕНИЕ

1. Распакуй архив обновления.
2. В GitHub открой репозиторий alex.
3. Add file → Upload files.
4. Загрузи всё содержимое архива в корень репозитория с заменой файлов.
5. Нажми Commit changes и дождись зелёной галочки GitHub Actions.

Для совместной игры отдельно настрой игровой Ably:
- добавь Supabase secret ABLY_GAME_API_KEY;
- разверни ably-game-token;
- разверни ably-game-control;
- у обеих функций отключи Legacy JWT verification.

Подробности находятся в INTEGRATION_0.9.0_RU.txt.
