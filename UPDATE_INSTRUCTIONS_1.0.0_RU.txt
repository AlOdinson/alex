Alex Board 1.0.0 — мгновенное письмо Pencil после zoom

Установка:
1. Новый SQL выполнять НЕ нужно.
2. Распакуй архив 1.0.0.
3. Загрузи содержимое архива в тот же GitHub-репозиторий с заменой старых файлов.
4. Дождись завершения GitHub Pages deploy.
5. Полностью закрой прежнюю вкладку Safari на iPad.
6. Открой сайт заново. Для обхода кэша один раз можно добавить к адресу ?v=1000.

Главная проверка:
1. Выбери карандаш.
2. Сделай zoom in или zoom out двумя пальцами.
3. Мгновенно после изменения масштаба начни писать Apple Pencil, не делая паузу.
4. Повтори 20–30 раз на большой доске.

Ожидаемое поведение:
- первый Pencil-down после zoom сразу начинает штрих;
- не требуется поднимать Pencil и касаться повторно;
- два оставшихся пальца не возобновляют zoom посреди Pencil-штриха;
- один палец продолжает рисовать при выбранном карандаше;
- два пальца без Pencil продолжают перемещать и масштабировать доску;
- частичный ластик после zoom работает сразу;
- Select, Text, Shape, Line, объектный ластик и пипетка не переключаются на карандаш;
- пользователь без права редактирования не получает режим рисования.
