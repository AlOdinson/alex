# Alex Board 1.25

## 1. Точная точка вставки у кнопок «Копировать» / «Вставить»

- После копирования через панель инструментов доска запоминает именно последующий клик по доске.
- Движение мыши от выбранной точки к кнопке «Вставить» больше не меняет координату вставки.
- `Ctrl/Cmd+C` и `Ctrl/Cmd+V` сохраняют прежнее независимое поведение.
- На сенсорных устройствах выбранная касанием точка используется той же кнопкой «Вставить».

## 2. Быстрая первоначальная загрузка на iPad, телефоне и компьютере

- Восстановление полного состояния Supabase начинается сразу и параллельно локальному кэшу.
- Доска больше не ждёт восстановления буфера обмена перед первым отображением.
- Онлайн-режим теперь использует свежий локальный snapshot, если он новее snapshot из ссылки доступа.
- Журнал подтверждённых и ожидающих операций применяется пакетно с одним клонированием snapshot вместо клонирования всей доски после каждой операции.
- После восстановления текущего состояния создаётся компактный полный серверный snapshot, поэтому следующее открытие на новом устройстве не должно долго проигрывать старый журнал.
- Компактный snapshot строится из JSON-операций, а не через полный обход живого Fabric Canvas. Это не возвращает прежнее зависание Apple Pencil после паузы.

## 3. Изображения больше не блокируют всю доску

- Текст, линии, фигуры и остальные объекты появляются до завершения загрузки всех изображений.
- На месте каждой ещё загружающейся картинки сразу показывается позиционный placeholder.
- До трёх изображений догружаются независимо и параллельно; одна медленная картинка не задерживает остальные.

## Совместимость

- Формат объектов и операций не изменён.
- Используется уже существующий RPC `save_board_snapshot`; новых SQL-миграций для версии 1.25 нет.
- Исправления 1.23, 1.24 и 1.24.1 сохранены.
