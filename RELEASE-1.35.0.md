# Alex Board 1.35.0

- Регистрация и вход по почте и паролю с подтверждением электронной почты.
- Восстановление и изменение пароля; старый magic-link вход оставлен для совместимости.
- Кнопка скачивания Mac-сервера в аккаунте учителя.
- Mac-сервер устанавливается как пользовательский LaunchAgent и работает без Terminal.
- Файл запуска открывает текущую службу или запускает остановленную.
- Кнопка отключения завершает службу штатно; после сбоя launchd восстанавливает её.
- Удаление отзывает токен Mac, останавливает службу, очищает локальные файлы и перемещает скачанный пакет в Корзину.
- Старые доски, ключи, ссылки, синхронизация и уже привязанный Mac сохраняются.
