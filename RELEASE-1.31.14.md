# Alex Board 1.31.14

Base: 1.31.13.

## Changes
- Extended drawing stroke-width choices from 1–24 px with two new steps: 50 px and 100 px.
- The same 50 px and 100 px choices are available when changing the width of selected objects.
- Drawing-style memory and eyedropper width transfer now accept widths up to 100 px.
- Kept all 1.31.13 selection, eraser, Pencil, large-board compositor, realtime and strokeUniform behavior unchanged.
