Alex Board 0.7.2 — одна метка группового редактирования

Что исправлено:
1. На принимающем устройстве показывается только одна надпись «Редактирует …» на всю группу, а не по одной надписи на каждый объект.
2. Метка привязывается к центру временной группы и не создаёт десятки DOM-элементов, которые мешали плавной анимации.
3. Живая трансформация группы продолжает передаваться одной матрицей временной группы с частотой до 20 Гц.
4. Простое выделение без перемещения/вращения/масштабирования/изменения стиля больше не переписывает объекты в Supabase при снятии выделения.
5. При снятии неизменённого выделения исходные объекты восстанавливаются локально без пустого кадра.

Установка:
- В Supabase и Ably ничего менять не нужно.
- Загрузите содержимое update-архива в корень GitHub-репозитория с заменой файлов.
- Дождитесь зелёного GitHub Actions и полностью закройте старые вкладки доски на обоих устройствах.
